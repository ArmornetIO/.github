# Armornet

**Securing the line to your software supply chain.**

Every dependency, editor extension and vendor behind your code gets named and scored — and cut off the moment one is found malicious.

[armornet.io](https://armornet.io) · [Request alpha access](mailto:alpha@armornet.io)

---

### / WHAT IT DOES

- **Blocks malicious packages before the breach disclosure.** Armornet's agents watch every package you pull. Flagged packages hit a wall. Clean code flows untouched.
- **Scores your vendors.** A live score, not last year's questionnaire.
- **Records every fetch.** Every package, version and vendor behind your code is named — laptop to CI.

### / HOW IT FITS TOGETHER

An **Armornet** server commands an **Armory** of **Agents**, connected by **Line**. Each Agent runs in one mode — DNS filtering, supply-chain proxy, threat monitoring — on a machine you run. Stopped in the path where we can, on the device where we must.
